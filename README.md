# Git & GitHub Learning Journey

Welcome to my Git & GitHub learning repository!

I created this repository to learn version control and practise Git and GitHub commands through hands-on exercises.

## About This Repository

As a B.Tech student in Artificial Intelligence and Data Science, I am building my technical foundation by learning how to manage code, track changes, and collaborate using Git and GitHub.

## Topics I Am Learning

* Git basics and version control
* Creating repositories with `git init`
* Checking changes with `git status` and `git diff`
* Staging and committing changes
* Viewing commit history with `git log`
* Undoing changes using `git restore`, `git reset`, and `git revert`
* Creating and managing branches
* Merging branches
* Connecting local repositories to GitHub
* Cloning repositories
* Uploading changes using `git push`
* Downloading changes using `git pull`
* Fetching updates using `git fetch`
* Ignoring unnecessary files using `.gitignore`

## My Learning Goal

My goal is to become confident with Git and GitHub so I can manage my future Python, AI, and Machine Learning projects professionally.
